# Dataset input directory

This folder contains documentation and inventory metadata only. Raw `.evtx` files are intentionally not included in this starter pack.

## Candidate sources
1. Hayabusa Sample EVTX: https://github.com/Yamato-Security/hayabusa-sample-evtx
2. EVTX-ATTACK-SAMPLES: https://github.com/sbousseaden/EVTX-ATTACK-SAMPLES

Download and extract the repositories locally, then select files only after checking their provenance, license, readability, timestamps, and suitability. Keep untouched originals separate from working copies. Do not commit raw logs to GitHub unless the team confirms the files are approved for redistribution.

See `docs/lab_setup.md` and `docs/source_authorization.md`.
